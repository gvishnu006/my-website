# Nova Studio

A fast, responsive, dependency-free static website built with plain HTML, CSS and vanilla JavaScript.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| About | `about.html` |
| Contact | `contact.html` |
| Not found | `404.html` |

## Features

- Dark theme with gradient accents
- Mobile-first responsive layout with hamburger nav
- Sticky blurred header
- Client-side contact form validation
- Zero dependencies, no build step

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Push to GitHub and enable GitHub Pages on the root of the `main` branch.
